# Евгений Лубский — портфолио

Сайт: https://jenechek.github.io/Portfolio/

Профессиональное портфолио руководителя направления интернет-маркетинга: e-commerce, недвижимость, аналитика и автоматизация. Максимальный рекламный бюджет — 17 млн ₽/мес.

## Страницы

- `index.html` — главная страница.
- `case-169.html` — развитие рекламных направлений в «169».
- `case-adv.html` — запуск и масштабирование проекта недвижимости.
- `case-deltaclick.html` — эффективность и масштабирование рекламы.

HTML, CSS и JavaScript без сборки и внешних зависимостей. Дизайн адаптирован для компьютеров и телефонов. Файл `assets/resume-brief.pdf` — актуальное краткое резюме.

## Локальный просмотр

Откройте `index.html` в браузере или запустите из папки проекта:

```sh
python3 -m http.server 8765
```

## GitHub Pages

Источник публикации: ветка `main`, папка `/ (root)`. Изменения в этой ветке автоматически обновляют сайт. Файл `.nojekyll` отключает обработку Jekyll.
